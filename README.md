# Evaluación de artículos para congresos

Página pública (envío de artículos y panel de evaluación). Es solo la parte visual:
los datos, archivos y validaciones viven en un Google Apps Script privado.

- `index.html?c=CODIGO` — formulario de envío de un congreso.
- `evaluar.html#CLAVE` — panel personal de cada evaluador.
- `config.js` — dirección del motor y nombre que se muestra.
